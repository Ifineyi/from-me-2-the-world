# Security Policy
## Reporting a Vulnerability
We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us as described below.
### How to Report a Security Vulnerability?
**Please do not report security vulnerabilities through public GitHub issues.**
Instead, please report them via GitHub's private vulnerability reporting feature:
1. Navigate to the repository's **Security** tab
2. Click on **Report a vulnerability**
3. Fill in the vulnerability details including:
   - **Affected version(s)**: Specify which versions are impacted
      - **Steps to reproduce**: Provide clear reproduction steps
         - **Impact**: Describe the potential security impact
         Once submitted, you will receive a confirmation email. Please do not discuss the vulnerability publicly until it has been resolved.
         ## Preferred Languages
         We prefer all communications to be in English or Chinese.
